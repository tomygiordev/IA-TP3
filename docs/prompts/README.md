## Criterio general

En todos los casos busque que los prompts:

- estuvieran bien acotados al TP y no a "machine learning" en general
- respetaran la consigna de usar una MLP con Keras Sequential
- me ayudaran a entender decisiones, no solo a copiar codigo
- dejaran espacio para que yo despues revise, cambie y justifique

Si hiciera una entrega formal, esta carpeta me sirve como evidencia de proceso y como base para explicar que tipo de ayuda le pedi a la IA en cada etapa.
